Xray Path

One control page for the full path: choose a VPS, let the router reach it over SSH, and keep router + VPS in sync. The physical switch on the router body remains the only ON/OFF control for the path itself and is re-applied automatically.

Selected VPS

Choose an existing VPS or create a new one. The router uses one host field for both SSH and Xray server address. Xray / Reality values are taken from the live VPS when present, or generated automatically for a new server.

Diagnose & Repair
Runs one connected pipeline: SSH check → binary → systemd unit → dirs → permissions → TLS cert → config → firewall → runtime. Each step self-heals when it can. Use this after a VPS reboot, reprovision, or when the path stops working.
SSH credentials required
The router's managed SSH key does not currently work on the VPS. Enter the VPS root password once so the router can re-install its managed key.
